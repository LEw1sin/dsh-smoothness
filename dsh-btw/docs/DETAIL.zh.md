# 旁聊

旁聊给当前的 DeepSeek Harness 会话加一个「侧边对话」：像 Claude Code 的
`/btw` 一样，问主 Agent 现在做到哪了、刚才为什么失败，或者干脆聊点别的，而
不会往主会话里增加任何内容。


## 你会得到什么

- 输入框下方一个 **旁聊** 按钮。
- 一个浮动面板，答案流式输出，主任务继续跑。
- 一份只读的会话快照：最近的消息、工具调用与结果、最新的 todo 列表，以及
  当前是否正在执行。
- 按会话保存在 Host 内存中的旁聊记录，追问能接上上下文。

主会话不会被写入：不会多出用户消息、助手消息、工具调用，也不会有任何 token
进入下一次主会话请求。

## 怎么用

1. 打开一个会话，在输入框下方找到 **旁聊**。
2. 问进度（“现在进展到哪了？”）、问失败原因（“刚才那步为什么失败？”），或者
   聊任何无关话题。
3. Enter 发送，Shift+Enter 换行。可以停止长回答、重试失败的回答、清空旁聊。

每个进行中的会话都可以打开旁聊。它使用该会话当前的模型；会话还没有发出过
模型请求时，回退到 profile 的默认模型。

## 能做什么、不能做什么

- 能读上面那份快照，并据此回答。
- 不能运行工具、改文件、改主会话。让它干活，它会把你指回主助手。
- 旁聊是刻意“不留痕”的：不写入会话日志、不能从日志回放，Host 重启即清空；
  刷新页面只清掉当前可见的线程。

## 隐私

快照会发送给该会话配置的模型提供方，使用与主对话相同的账号和线路。快照只保留
最近的事件，超预算时先丢更早的记录。旁聊不会上传文件，也不会执行工具。

## 要求

- DeepSeek Harness `>=0.2.1-rc.3 <0.3.0`。
- Web UI（面板使用 composer dock 与 frame overlay）。
- 已挂载 `llm` 提供方，以及 `connection`、`sessions` 服务；官方 Web profile
  默认都有。

## 安装

```sh
dsh plugin --profile web add <包名>
```

这个包是纯 JavaScript，没有构建步骤；也可以直接从 Git 安装：

```sh
dsh plugin --profile web add github:<owner>/<repo>#<commit>
```

装完如果没看到按钮，刷新一下 Web UI。
